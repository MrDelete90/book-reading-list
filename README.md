# Book Reading List Application

A simple web application to manage a personal reading list. Users can add books, mark them as read or unread, delete them and filter the list. Data is saved in the browser using localStorage.

## Features
- Add a book with title and author
- Mark books as Read or Unread
- Delete books
- Filter by All, Unread and Read
- Live counter of total, read and unread books
- Data saved with localStorage

## How It Works
- Books are stored in a JavaScript array of objects (id, title, author, read).
- The array is saved as JSON in localStorage after every change.
- The list is redrawn from the array each time using a render function.

## Technologies Used
HTML, CSS, JavaScript

## How to Run
Open `index.html` in a browser.
